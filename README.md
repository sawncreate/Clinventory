# ClinicStock

Tahap awal aplikasi inventaris klinik menggunakan React, Vite, dan JavaScript.
Saat ini hanya ada halaman pengenalan dan kerangka dashboard; belum ada data
inventaris yang aktif atau koneksi Supabase.

## Menjalankan aplikasi

```sh
npm install
npm run dev
```

Vite akan menampilkan alamat lokal (biasanya `http://localhost:5173`). Buka
alamat tersebut di browser.

## Memeriksa build

```sh
npm run build
npm run preview
```

## Struktur sumber

- `src/main.jsx` — titik masuk React.
- `src/App.jsx` — router dan layout aplikasi.
- `src/components/` — komponen tampilan yang dipakai ulang.
- `src/pages/` — halaman aplikasi.
- `src/styles.css` — warna, layout, dan gaya global.
